# Languages (i18n)

UI texts use [i18next](https://www.i18next.com/) in English (default), French, Dutch and German.

```
client/src/i18n/
├── index.ts          t(), tHtml(), tList(), getLanguage() – the i18next setup
├── languages.ts      the language list, names, device-language detection
├── en/               English – the reference: one file per domain (page or area)
│   ├── about.ts  camera.ts  common.ts  entries.ts  entry.ts  header.ts  home.ts
│   ├── notFound.ts  progress.ts  scan.ts  settings.ts  startup.ts  tutorial.ts
│   └── index.ts      all domains → the `Messages` type
├── fr/  nl/  de/     the same files; TypeScript requires exactly the English keys
```

Each domain is an i18next namespace. In code:

```typescript
import { t, tHtml, tList } from "@/i18n";

t("entry.accessPage");                    // "Access page"
t("entry.goToPage", { page: 4 });         // placeholders: {page}
`<p>${tHtml("entries.empty")}</p>`;       // escaped for HTML templates
tList("camera.chromeSteps");              // lists
```

Keys are checked by TypeScript; a test checks that every language has every text, none is empty, and
the placeholders match English.

**Adding a language:** add it to `LANGUAGES` / `LANGUAGE_NAMES` in `languages.ts`, copy `en/` to the new
folder, translate, register it in `index.ts` (`RESOURCES`).

**Adding a text:** add the key to the English domain file, then to every other language (the build fails
until all have it).

## The reader's language

- Stored in the settings (`services/SettingsService.ts`, localStorage key `osct-settings`), **not** in the
  progress: progress is per book and "Reset book" deletes it; the language belongs to the reader across
  books and stays. Later the settings map to the account settings of the API, the progress to per-book
  save data.
- Without a choice the device's language is used (first supported one of `navigator.languages`, else
  English).
- Changed in Info → Settings → Language; the app reloads and stays on the same view (the URL keeps it).

**Not translated (yet):** the book content – titles, entry texts, onboarding step texts, book info – comes
from `content/` as it is.
