# Languages (i18n)

UI texts use [i18next](https://www.i18next.com/) with the
[browser language detector](https://github.com/i18next/i18next-browser-languageDetector), in English
(default), French, Dutch and German – informal everywhere ("tu", "je", "du").

```
client/src/i18n/
├── index.ts          i18next setup (resources, fallback, detector) – imported first in main.ts
├── i18next.d.ts      typed keys (CustomTypeOptions)
├── languages.ts      language list and names
├── en/               English – the reference: one file per domain (page or area) = i18next namespace
│   ├── about.ts  camera.ts  common.ts  entries.ts  entry.ts  header.ts  home.ts
│   ├── notFound.ts  progress.ts  scan.ts  settings.ts  startup.ts  tutorial.ts
│   └── index.ts      all domains → the `Messages` type
├── fr/  nl/  de/     the same files; TypeScript requires exactly the English keys
```

Components use i18next directly:

```typescript
import i18next from "i18next";

i18next.t("entry:accessPage");                            // "Access page"
i18next.t("entry:goToPage", { page: 4 });                 // placeholders {{page}}; values are escaped for HTML
i18next.t("camera:chromeSteps", { returnObjects: true }); // lists
```

Keys (`namespace:key`) are checked by TypeScript. A test checks that every language has every text,
none is empty, and the placeholders match English.

**Adding a language:** add it to `LANGUAGES` / `LANGUAGE_NAMES` in `languages.ts`, copy `en/` to the new
folder, translate, add it to `resources` in `index.ts`.

**Adding a text:** add the key to the English domain file, then to every other language (the build fails
until all have it).

## The reader's language

- The language detector keeps it in localStorage (`osct-language`) – the reader's choice, or on the first
  visit the device's language (first supported one of `navigator.languages`, else English).
- It is not part of the progress: progress is per book and "Reset book" deletes it; the language belongs
  to the reader across books and stays. Later it maps to the account settings of the API.
- Changed in Info → Settings → Language (`i18next.changeLanguage`); the app reloads and stays on the same
  view (the URL keeps it).

**Not translated (yet):** the book content – titles, entry texts, onboarding step texts, book info – comes
from `content/` as it is.
