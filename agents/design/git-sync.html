  • The dialog is Publish's dialog with a message field: what changed since the last commit, then Commit / Cancel. The whole export goes in as one commit; git works out the files.

Notes.
  • No merging. When both sides changed, a person picks one side; git keeps the other.
  • Compare… is the existing import comparison (confirm-import), here with the repository as its source – the same source Replace… in the Manage sheet gets as a fourth choice next to file, URL and published.
  • Without saves of its own the editor never asks: a push comes in by itself (frame 5) and the item says In sync again.
