# Reference scenes (`*.ref.ts`)

Hand-written A-Frame scenes from before the content build generated them. **Not imported** – the
live scene HTML is generated from `game.config.json` by `../utils/templates.ts` and injected by
`../static-scene-bridge.ts`. Kept as reference for the DOM-replacement approach until Phase 6
(A-Frame bridges). Target indices predate the entries pipeline (Phase 1d).
