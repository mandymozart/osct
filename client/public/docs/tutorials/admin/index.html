Tutorials for admins

The admin page is at /admin (it opens /editor/admin). It manages who may edit, counts arrivals from printed QR codes, and exports the newsletter list.

1 · Get in

  1. You need the role admin. The first admins of an installation are the addresses in its ADMINS setting: they get the role when they sign in. Everyone else is made an admin by an admin (tutorial 3).

  2. Open /admin and sign in with your e-mail and the code you receive, or your password.

An editor who is no admin sees No admin access there. An admin who is no editor sees only this page.

2 · Invite an editor

  1. Scroll to Invite an editor, type the person's e-mail, press Make editor.

  2. Tell them to open /editor and sign in with that address. They get a code by mail; no password is needed.

A new address becomes an account at once. An existing account simply gets the role.

3 · Change someone's roles

  1. Under Users, search by a part of the e-mail, or use the filters Editors and Admins.

  2. Flip the editor or admin switch in their row. It takes effect with their next request.

  3. Hover a role to see when and by whom it was given.

reader is fixed: every account has it. The last admin cannot give up the role; make another admin first.

4 · Make a QR code for print

Give every printed code or link its own source, so you can tell where people come from.

  1. Under A new code, type a short source: letters, digits and dashes, e.g. fl1 for a flyer.

  2. Choose where it leads to: the start, Info, a scene, an entry list or an entry.

  3. The address and its QR code appear. Copy the address or Download SVG for the printer.

5 · Read the arrivals

  1. At the top, choose the window: 7, 30 or 90 days, or a year.

  2. Each source shows its arrivals in that window and in all, the first arrivals (browsers that had never come before), phone · tablet · desktop, and a bar per day.

These are counts only: no IP address and no user is stored. A source shows up with its first arrival.

6 · Export the newsletter list

  1. Under Users, press the filter Newsletter: the readers who opted into news.

  2. Press Newsletter CSV. The file has e-mail, language, the option and the sign-up date, ready for a mailing tool.

With the filter All the button is Users CSV and downloads every user. The page shows a reader's choice; it cannot change it. Readers change it themselves under Info → Account.

7 · Bring an experience onto a new installation

  1. Sign in at /editor (you need the editor role too).

  2. Use Import an experience: the CDN's version, or a content base URL from another installation. How importing works

  3. Open the experience, check a few scenes, then Publish. This installation publishes to its own environment only.
