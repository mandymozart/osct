Editor guide

The Logic panel

The Logic panel draws what the rules and plugins do as a graph: which event sets off which rule, what the rule reads, and what it changes. It shows one level at a time.

Open it from the panels menu in the top bar. How rules work is in the logic system; this page is about the panel.

What the boxes are

BoxStands for
EventA node's found, lost, tap, unlocked, a scene event, or a core event.
RuleOne rule of a behaviour, of the scene or of the experience.
VariableA variable the rules read or set.
NodeA node the rules play, pause, stop, show or hide. Its ports come from its type and components.
PluginCode that hears or emits events, or reads or sets variables.
StubAt the edge: something that crosses into another level, named by its far end (hasKey ← set in 1–2).

The legend under the bar gives the colour and shape of each signal: event, control, picture, address, scene and so on.

Levels

Experience → group → scene → entity. The breadcrumb shows where you are.

  • Go in: double-click a box, or its arrow. Go up: the breadcrumb, ↑ or Backspace.
  • Search finds any box of the experience and opens its level.
  • With Follow on, selecting something on the stage or in the tree moves the view to it. Entering a scene here opens that scene.

Watching it run

With Trace on (in the bar's … view settings, beside Follow – on by default), the canvas shows what is happening on the stage as it happens:

  • An event fires: every wire that carries it lights up in its colour for a moment, a glow running along it from where it comes from to where it goes.
  • A variable changes: its wires light up, and its box shows the new value for a moment.
  • A rule runs: its box pulses, and the wires out of its actions light up.

Only what happens from now on shows – opening the panel does not replay the past. Tap a target on the stage and watch the logic move. If your system asks for reduced motion, the wires only brighten. Turn Trace off to keep the canvas still.

Setting things off by hand

To see what an event would set off down the line, right-click a box while the stage runs:

BoxItemWhat happens
An eventFire on stage, or Fire with a payload…The event goes out on the stage as a plugin would send it: the rules that hear it run, the plugins hear it. Type a payload as key: value pairs, for example door: front, tries: 2. With a mouse, the ▶ on the box's head fires it at once.
A node's tapTap on stageThe reader's tap on that target – while it is found on the stage.
A variableSet on stage…Pick true or false, or type a number or a text; the rules and plugins hear the change.
A ruleRun this ruleIts actions, as if its event had come. Its condition still applies – if it is false, nothing runs. No other rule runs.

The Log marks these lines by hand, and Trace lights the wires. Only the running stage changes, never your draft – Restart on the stage puts it back. It works on read-only levels too. Core events such as targetFound come from the stage itself: find or tap the target instead. A rule of another scene runs once that scene is open.

Editing

You can edit on a scene's and an entity's level of the open scene, and on the experience level. The group level is read-only.

ToDo
Make a rule hear an eventDrag from the event's outlet to the rule's on.
Add a conditionDrag a variable into the rule's when.
Add an actionDrag from the rule's + to a node (show), a variable (set), an event (emit) or a scene (goto).
Add a rule, action or termRight-click the canvas, or the bar's +.
RemoveSelect a wire, a rule or a note and press Delete.

While you drag a wire, only the ports that can take it light up. A wire that does not fit says why under the bar. Every change shows on the stage at once, saves itself, and is a step you can undo.

Fine-tune a rule in the Inspector: the verb, the value, the scope. The canvas and the Inspector edit the same rules.

Arranging the canvas

  • Drag a box by its head to place it. Tidy lets the layout place everything again.
  • Group (or Ctrl+G) frames the selected boxes; a group has a name and a colour and folds to one pill.
  • Click a group's head to select its boxes (Shift adds them). Right-click the head for its menu: select, rename, colour, fold and Ungroup. Ctrl+Shift+G ungroups the groups of the selected boxes; the boxes stay where they are.
  • A box hides its unused ports. Its + shows more; Ctrl+H hides the unused ones again.

The arrangement is saved with the draft. It is authoring data: readers never get it.

Notes

Notes are annotations on the canvas – they are not logic and change nothing. Right-click the empty canvas and choose Add note, or press N with the pointer over the canvas. Add note on a box's right-click menu puts the note beside the box: it moves with the box, joined by a dotted line.

  • Type the text; Ctrl+Enter or clicking elsewhere keeps it, Esc goes back. Double-click a note to edit it again.
  • A note shows who wrote it. Drag it anywhere; select it and press Delete to remove it (an empty note goes too).
  • When the rule beside it is removed, the note stays where it was.

Problems

Under the graph, in red: a variable that is read but never set, an event that is heard but never emitted (or emitted but never heard), a node an action names that is not there, and type problems in conditions.

Events do not travel between scenes. Only the open scene's rules exist, so an event one scene emits never reaches another scene's rules; such wires are dotted and labelled never fires. Use a variable to carry state across scenes, or an experience rule.
